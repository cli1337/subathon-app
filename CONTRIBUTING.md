# Contributing to Subathon App

Thank you for your interest in contributing to Subathon App! This document provides guidelines and instructions for contributing.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/subathon-app.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Commit your changes: `git commit -m 'Add some feature'`
6. Push to the branch: `git push origin feature/your-feature-name`
7. Open a Pull Request

## Code Style

- Use consistent indentation (spaces, not tabs)
- Follow existing code patterns
- Add comments for complex logic
- Keep functions focused and small

## Commit Messages

Please write clear commit messages:
- Use the present tense ("Add feature" not "Added feature")
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...")
- Limit the first line to 72 characters or less
- Reference issues and pull requests liberally

## Pull Request Process

1. Update the README.md with details of changes if needed
2. Update the CHANGELOG.md with your changes
3. Ensure your code follows the existing style
4. Test your changes thoroughly
5. The PR will be reviewed and merged if approved

## Reporting Bugs

When reporting bugs, please include:
- Description of the bug
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots if applicable
- Your environment (OS, Node version, etc.)

## Feature Requests

Feature requests are welcome! Please provide:
- Clear description of the feature
- Use case or motivation
- Possible implementation approach (if you have ideas)

## Questions?

Feel free to open an issue for any questions or concerns.

Thank you for contributing! 🎉
