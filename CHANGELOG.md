# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-XX

### Added
- Initial release of Subathon App
- Kick.com platform integration with websocket connection
- Twitch platform integration with IRC connection
- Real-time subscription and gift subscription event detection
- Customizable overlay system for OBS integration
- Multiple metric types (time, distance, custom units)
- Profile management system
- Reducer system for automatic value reduction
- Manual event entry
- Connection status indicators for platforms
- Platform switcher UI with animations
- Keyboard navigation (Tab key for sidebar navigation)
- External link handling (opens in default browser)
- Real-time dashboard with statistics
- Event history tracking
- Configurable event values (subs, gifts, bits, donations, follows)
- Fully customizable overlay styling
- Pause/resume functionality
- Auto-save configuration

### Features
- Web-based overlay accessible via localhost
- Multiple animation options for gifter cards
- Custom font sizes, colors, and positioning
- Background and text shadow customization
- Paused/stopped state displays
- Unit prefix/suffix configuration
